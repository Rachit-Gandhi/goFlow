# AGENTS.md

Instructions for AI agents working in this repo.

## Agent skills

### Issue tracker

GitHub Issues is the primary tracker (`gh issue create`); a local `.scratch/` mirror is maintained as a hardened copy. See `docs/agents/issue-tracker.md`.

### Triage labels

Default label vocabulary — `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context repo — `CONTEXT.md` and `docs/adr/` live at the repo root. See `docs/agents/domain.md`.
